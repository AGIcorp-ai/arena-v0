How Arena v0 works

Arena v0 is a log-first sandbox for self-improving agents. It’s designed so a skeptical engineer can replay and audit claims from artifacts. This page explains the mechanics, the proof bundle, and where public participation plugs in.
Runner llama
Model (simulated)
Determinism seed + append-only hash-chained log
Default 8 creatures, permadeath via layers
Kill mints 1-of-1 TacticCard Adapter tokens trigger async mutation jobs Audience votes steer next challenge (ghost fallback)

Participation, without blocking progress

Arena runs even with zero users. When no public actions are queued, a deterministic “Ghost Crowd” emits and applies actions in the log. The moment you have users, you can swap in real submissions without refactoring the engine. 
# Queue a vote for the next auction trial type
arena-v0 audience-vote --log data/global_log.jsonl --arena-id <world_or_arena_id> --trial-type arc --submitted-by yourname

Key invariants (v0 contract)

- Default arena: 8 creatures
- Permadeath: layers == 0
- Each kill mints a unique (1-of-1) tradeable TacticCard
- Adapter token spend triggers async mutation job (sim ok)
- Full artifact retention (trial IO, traces)
- Global append-only hash-chained event log
- Deterministic replay from seed + logged events
